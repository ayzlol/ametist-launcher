# Ametist Launcher v1.2.1

Ametist Launcher v1.2.1 is the current full release of a simple, open-source Minecraft launcher for Windows and Linux.

Ametist lets you choose a username, select a Minecraft version and loader, configure RAM, and launch the game from one focused interface.

## Downloads

| Platform | File | How to start |
|---|---|---|
| Windows | `AmetistLauncher.exe` | Download and double-click the file. |
| Linux | `AmetistLauncher-x86_64.AppImage` | Run `chmod +x AmetistLauncher-x86_64.AppImage`, then start the file. |

The packaged files include Python and the project dependencies. Minecraft still requires a compatible Java Runtime Environment.

## Included features

- Vanilla, Fabric, Forge, and Quilt version selection and launching
- Offline username login
- Automatic Minecraft and loader file installation
- Internet connection monitoring
- Local version detection when offline
- Dynamic or manual RAM allocation
- JVM performance options
- English, Turkish, Russian, and Spanish interface translations
- Dark interface
- Left or right version-panel layout
- Custom background and avatar support
- Local mods-folder access
- System, operating system, architecture, Python, and RAM information
- Persistent settings in the `.ametist_mc` directory

## Getting started

1. Download the package for your operating system.
2. Install a compatible Java Runtime Environment if it is not already installed.
3. Start Ametist and enter an offline username.
4. Select Vanilla, Fabric, Forge, or Quilt.
5. Choose a Minecraft version and RAM amount.
6. Press Launch.

The first installation of a Minecraft version or loader requires an internet connection. When the connection is unavailable, Ametist lists the compatible versions already installed locally.

## Important information

This release uses offline username login. It does not provide Microsoft account authentication. The Mods tab opens the local mods folder; it does not include an online Modrinth or CurseForge browser.

The application is distributed as a full release, but behavior can still vary between operating systems, Java versions, and Minecraft versions. If you find a problem, please report it with your operating system, Java version, Minecraft version, selected loader, and the exact error message.
