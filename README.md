# 🚀 Ametist Launcher – Vanilla & Fabric

> **A lightweight, open-source Minecraft launcher built with Python and CustomTkinter.**  
> **✅ Currently supports: Vanilla | Fabric**

![Ametist Launcher](Ekran%20G%C3%B6r%C3%BCnt%C3%BCs%C3%BC%202026-07-31%2022-10-07.png)

---

## ⚡ Quick Overview
- **Vanilla & Fabric** support
- **Offline mode** only (Microsoft login coming soon)
- **Custom avatar/skin** (experimental)
- **RAM allocation** (2–16 GB)
- **Multi-language**: Turkish, English, Chinese, Russian
- **Auto-install** Minecraft & Fabric
