# Ametist Launcher Bundled Fonts

Ametist Launcher bundles the following open-source fonts for consistent rendering across Windows, Linux, and macOS packages:

- **Inter Variable** — [rsms/inter](https://github.com/rsms/inter), licensed under the SIL Open Font License 1.1.
- **JetBrains Mono** — [JetBrains/JetBrainsMono](https://github.com/JetBrains/JetBrainsMono), licensed under the SIL Open Font License 1.1.
- **Montserrat** — [google/fonts](https://github.com/google/fonts/tree/main/ofl/montserrat), licensed under the SIL Open Font License 1.1.

The font files are distributed only as application UI assets. See the upstream repositories for the complete license texts and notices.

## Usage in the launcher

- Inter Variable: general interface text, labels, dropdowns, and version list.
- JetBrains Mono: game file paths and system/hardware details.
- Montserrat: headings, welcome text, launcher version, and the main launch action.
